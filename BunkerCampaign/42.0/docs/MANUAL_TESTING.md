# Ручное тестирование в multiplayer

## Подготовка

1. Сделать резервную копию тестового мира.
2. Для изолированной проверки включить локальный мод `BunkerCampaign` на сервере и у клиентов.
3. Для полной проверки включить также MP-форки и `BunkerCampaignIntegration` по его `docs/MANUAL_TESTING.md`.
4. Запустить кооперативный мир Build 42.19 минимум с двумя клиентами.
5. Одному аккаунту выдать роль `admin`, второй оставить обычным игроком.

## Инициализация и интерфейс

1. На обоих клиентах щёлкнуть правой кнопкой по земле.
2. Выбрать `Bunker: systems status`.
3. Убедиться, что начальные значения: включена, исправность 100%, фильтр 100%, CO2 400 ppm, статус `operational`.
4. Сверить номер ревизии на обоих клиентах после нажатия `Refresh`.

Ожидаемый результат: оба клиента получают одинаковый снимок. У обычного игрока кнопка управления неактивна.

## Авторитетность сервера

1. Администратором выключить вентиляцию.
2. На втором клиенте нажать «Обновить».
3. Подождать пять игровых минут и обновить оба окна.

Ожидаемый результат: состояние `enabled=false` одинаково у клиентов, CO2 увеличивается только по серверному расчёту, а в журнале указаны пользователь и переключение.

Для проверки плохого пакета из клиентской debug Lua-консоли отправить:

```lua
sendClientCommand(getPlayer(), "BunkerCampaign", "setVentilation", { enabled = "yes" })
```

Ожидаемый результат: состояние не меняется, клиент получает `invalid_payload`, серверный журнал содержит запись `rejected malformed ventilation command`.

Повторить корректный пакет от обычного игрока:

```lua
sendClientCommand(getPlayer(), "BunkerCampaign", "setVentilation", { enabled = false })
```

Ожидаемый результат: состояние не меняется, ответ `admin_required`, отказ записан в журнал.

## Сохранение

1. Записать ревизию, CO2 и состояние переключателя.
2. Корректно остановить сервер.
3. Запустить тот же мир повторно.
4. Открыть окно и нажать «Обновить».

Ожидаемый результат: переключатель, CO2, фильтр и журнал продолжаются с сохранённого состояния; новая таблица кампании не создаётся.

## Проверка интегрированных систем

Загрязнение воздухозаборников и вода проверяются только в полном профиле с
`BunkerCampaignIntegration`. В окне появится раздел `WATER`; точный сценарий
находится в документации интеграционного мода.

## Логи

В `console.txt`/серверной консоли искать префикс `[BunkerCampaign]`. Не должно быть Lua stack trace или сообщений о неизвестном `require`.
