# Полная проверка второго среза: загрязнение и дезактивация

Целевая версия игры: **Project Zomboid 42.19**.

Документ проверяет второй срез на dedicated-сервере с администратором и как минимум одним обычным клиентом. Проверка считается законченной только после прохождения всех обязательных разделов и повторного запуска сервера.

## 1. Проверяемая сборка

Включить:

- `Bandits2`;
- `Waterpipes`;
- `BunkerCampaign` 0.4.0;
- `BunkerCampaignArkMP` 0.4.5;
- `BunkerCampaignToxicMP` 0.4.0;
- `BunkerCampaignIntegration` 0.6.0.

Отключить:

- оригинальный `TheArk`;
- оригинальный `ToxicZonesSTALKERB42`;
- `BanditsDayOne` и `BanditsWeekOne`;
- Cryogenic Winter.

Перед проверкой сделать резервную копию сохранения сервера. Не проводить первую проверку на единственном экземпляре важного мира.

## 2. Что добавлено

- отдельное серверное поверхностное загрязнение тела;
- загрязнение надетой экипировки и до 80 переносимых предметов за пакетный проход;
- сохранение загрязнения в `modData` предметов;
- отображение загрязнения тела, экипировки и отдельных предметов;
- физическая камера дезактивации Ark на уровне `z=-4`;
- NBC-смеситель с загрузкой существующих `Bandits.NBCTablets`;
- ручной, аварийный и автоматический циклы;
- списание чистой воды непосредственно из хранилищ Waterpipes;
- отдельный потребитель электроэнергии `decontamination`;
- сохранение активного цикла и концентрации реагента;
- временное администраторское QA-меню.

## 3. Временное QA-меню

Администратор щёлкает правой кнопкой по миру и открывает `Bunker Campaign: QA tools`.

Обычный игрок это меню видеть не должен.

Доступные действия:

| Кнопка | Результат |
|---|---|
| `[QA] Exterior toxic zone` | Создаёт тестовую зону и телепортирует на поверхность в заражённую область |
| `[QA] Dirty entrance` | Телепортирует к грязной стороне камеры |
| `[QA] Decontamination chamber` | Телепортирует внутрь камеры |
| `[QA] Clean-side exit` | Телепортирует к чистой стороне |
| `[QA] NBC tablet locker` | Телепортирует к шкафчику с таблетками на `z=-5` |
| `[QA] Set body and worn gear to 80%` | Мгновенно загрязняет тело и надетые предметы |
| `[QA] Reset body and worn gear contamination` | Очищает тело и надетые предметы |
| `[QA] Give tablets and cleaning agents` | Выдаёт 3 NBC-таблетки, чистящее средство и отбеливатель |
| `[QA] Fill bunker water storage` | Заполняет зарегистрированные бункерные ёмкости Waterpipes чистой водой |
| `[QA] Complete active cycle now` | Устанавливает оставшееся время текущего цикла в ноль |
| `[QA] Create exterior test zone` | Создаёт зону без телепортации |
| `[QA] Remove exterior test zone` | Удаляет временную зону |

Все кнопки отправляют запрос серверу. Клиент не изменяет координаты, воду, загрязнение или предметы самостоятельно.

## 4. Контрольные координаты

Они нужны только для диагностики. В обычной проверке использовать QA-кнопки.

| Место | Координаты |
|---|---|
| Поверхностная тестовая точка | `9928.5, 12625.5, 0` |
| Грязная сторона | `9942.5, 12625.5, -4` |
| Камера | `9946.5, 12625.5, -4` |
| Чистая сторона | `9951.5, 12625.5, -4` |
| Шкафчик NBC-таблеток | `9950.5, 12621.5, -5` |

Фактические границы камеры берутся из `BWOARooms.DecontaminationChamber`: `x=9944..9949`, `y=12622..12628`, `z=-4`. Устаревшая координата одиночного `gmd.decontaminator` не используется.

## 5. Базовая регрессия первого среза

Перед новой механикой убедиться:

1. Администратор и обычный клиент входят в бункер.
2. Повторный вход и reconnect работают.
3. Этажи `-4`, `-5` и `-7` существуют.
4. Основной генератор питает вентиляцию, воду и освещение.
5. Насос Waterpipes работает и создаёт запас воды.
6. Маска с фильтром останавливает рост `TOXIC EXPOSURE`.
7. Заряд фильтра уменьшается и сохраняется после извлечения/установки.
8. Нормальный и аварийный свет работают как в принятой версии Ark MP 0.4.5.

Любая поломка этого раздела является регрессией и блокирует принятие второго среза.

## 6. Накопление поверхностного загрязнения

1. Администратору надеть несколько предметов одежды, взять оружие и положить обычный предмет в рюкзак.
2. Надеть исправную маску с фильтром.
3. Нажать `[QA] Exterior toxic zone`.
4. Оставаться в зоне 10–20 секунд.
5. Проверить верхнюю центральную индикацию.

Ожидается:

- `TOXIC EXPOSURE` не растёт либо растёт согласно фактической защите маски;
- `SURFACE` растёт независимо от маски;
- `GEAR` растёт;
- tooltip загрязнённого предмета содержит `Surface contamination: N.N%`;
- заряд фильтра продолжает расходоваться отдельно;
- сервер не печатает ошибку каждый тик.

Затем выйти из зоны или телепортироваться к грязной стороне. Поверхностное загрязнение не должно автоматически исчезнуть.

## 7. Смерть и новый персонаж

1. Загрязнить персонажа и экипировку.
2. Умереть или использовать отдельную тестовую копию персонажа.
3. Создать замену под тем же сетевым пользователем.

Ожидается:

- `TOXIC EXPOSURE` нового тела равен нулю;
- поверхностное загрязнение нового тела равно нулю;
- предметы, оставшиеся на старом теле или в мире, сохраняют своё загрязнение;
- поднятый старый загрязнённый предмет снова отображает процент.

## 8. Загрузка NBC-смесителя

Ускоренный путь:

1. `[QA] Give tablets and cleaning agents`.
2. `[QA] Decontamination chamber`.
3. Правый клик → `Bunker Campaign: Decontamination`.
4. Нажать `Load NBC tablet into mixer (+50%)`.

Ожидается:

- одна таблетка исчезает из инвентаря;
- значение `NBC` становится `50%`;
- повторная таблетка поднимает его до `100%`;
- попытка загрузить ещё одну возвращает `mixer_full` и не съедает предмет.

Проверка существующего размещения:

1. Нажать `[QA] NBC tablet locker`.
2. Найти шкафчик в точке `9950,12621,-5`.
3. Убедиться, что в нём присутствуют подготовленные Ark MP таблетки, если шкафчик ранее не был разграблен.

## 9. Ручная очистка

Стоимость: **2 литра чистой воды** и одно из средств `CleaningLiquid2`, `Bleach` или `Soap`. Электричество не требуется. Время — 8 секунд.

1. Заполнить воду QA-кнопкой.
2. Выдать расходники.
3. Установить загрязнение 80%.
4. Отключить оба генератора, чтобы доказать независимость ручного режима от сети.
5. Находясь у камеры, выбрать `Manual item wash`.
6. Дождаться завершения или нажать `[QA] Complete active cycle now`.

Ожидается:

- вода уменьшается ровно на 2 литра;
- один чистящий предмет расходуется;
- загрязнение тела уменьшается на 50% от текущего значения;
- очищается только самый загрязнённый переносимый предмет;
- с него снимается 35% текущего загрязнения;
- потребитель `decontamination` не запрашивает питание.

## 10. Аварийная очистка

Стоимость: **5 литров чистой воды** и **2% NBC-смесителя**. Электричество не требуется. Время — 10 секунд.

1. Загрузить одну таблетку в смеситель.
2. Установить загрязнение 80%.
3. Зафиксировать воду и NBC до запуска.
4. Запустить `Emergency rinse`.
5. Завершить цикл.

Ожидается:

- вода уменьшается ровно на 5 литров;
- NBC уменьшается ровно на 2 процентных пункта;
- тело оставляет 20% прежнего загрязнения;
- вся обработанная экипировка оставляет 50% прежнего загрязнения;
- отсутствие электроэнергии не мешает запуску.

## 11. Автоматическая камера

Стоимость: **20 литров чистой воды**, **5% NBC-смесителя** и **2.5 kW** выделенной мощности. Время — 20 секунд.

1. Включить основной или резервный генератор с достаточной свободной мощностью.
2. Заполнить воду.
3. Загрузить NBC-смеситель.
4. Установить загрязнение 80%.
5. Запустить `Automatic full cycle`.

Во время работы ожидается:

- статус `running`;
- обратный отсчёт уменьшается;
- потребитель `decontamination` имеет `requested=true` и `allocated=true`;
- вода и NBC списываются один раз при успешном старте;
- второй игрок не может запустить параллельный цикл и получает `cycle_active`.

После завершения ожидается:

- тело и обработанные переносимые предметы имеют 0%;
- камера возвращается в `idle`;
- запрос питания `decontamination` снимается;
- повторная отправка старой команды не создаёт второй результат и не возвращает ресурсы.

## 12. Отказы ресурсов

Каждый подпункт начинать без активного цикла.

### Нет чистой воды

Израсходовать или временно опустошить бункерные ёмкости и запустить режим.

Ожидается `clean_water_required`; NBC и чистящее средство не расходуются, цикл не появляется.

### Вода заражена

Оставить в Waterpipes только `TaintedWater`.

Ожидается тот же отказ: камера считает доступной только воду с типом `Water`.

### Нет чистящего средства

Запустить ручной режим без допустимого предмета.

Ожидается `cleaning_agent_required`; вода не списывается.

### Нет NBC

Запустить аварийный или автоматический режим при NBC ниже стоимости.

Ожидается `nbc_solution_required`; вода не списывается.

### Нет мощности

Остановить генераторы и разрядить/оставить аварийную батарею. Автоматический режим не имеет права работать от батареи.

Ожидается `power_required`; вода и NBC не списываются. Ручной и аварийный режимы по-прежнему доступны.

## 13. Потеря мощности во время автоматического цикла

1. Запустить автоматический цикл.
2. После нескольких секунд остановить питающий генератор.
3. Подождать обновления энергосистемы.

Ожидается:

- статус переходит в `paused`;
- оставшееся время не уменьшается;
- вода и NBC повторно не списываются;
- после восстановления выделенной мощности цикл продолжает работу;
- после завершения ресурсы не списываются второй раз.

## 14. Disconnect и restart

### Disconnect владельца цикла

1. Запустить автоматический цикл обычным клиентом.
2. Отключить клиента до завершения.
3. Подключить его снова.

Ожидается: цикл не дублируется. Если таймер уже дошёл до нуля, состояние ждёт владельца в `paused` и завершает очистку после возвращения.

### Restart сервера

1. Запустить цикл и зафиксировать оставшееся время, NBC и воду.
2. Корректно остановить сервер.
3. Запустить сервер и подключиться снова.

Ожидается:

- концентрация NBC сохранена;
- активный цикл сохранён;
- автоматический цикл снова запрашивает питание;
- вода не списывается повторно;
- после завершения камера возвращается в `idle`.

## 15. Грязная и чистая стороны

1. Установить загрязнение 80%.
2. Телепортироваться к чистой стороне.
3. Обновить статус через контекстное меню камеры.

Ожидается предупреждение `WARNING: DIRTY LOAD ON CLEAN SIDE`.

Зайти загрязнённым в саму камеру. Значение загрязнения помещения должно стать ненулевым и попасть в серверное состояние. Полный автоматический цикл уменьшает загрязнение камеры.

## 16. Проверка прав и подделки команд

Обычный клиент:

- не видит `QA tools`;
- может пользоваться обычным меню камеры только рядом с ней;
- получает `decon_access_required`, если вручную отправляет команду издалека;
- не может задавать количество воды, эффективность очистки, NBC или время цикла;
- не может выполнить команду с префиксом `qa` и получает `admin_required`.

Дополнительно отправить с клиента неизвестную команду. Она должна быть отклонена как `unknown_command` и записана в журнал безопасности.

## 17. Нагрузка и серверная консоль

Провести 10 минут с двумя игроками, несколькими рюкзаками и большим инвентарём.

Ожидается:

- нет ошибки каждый тик;
- нет постоянного сообщения о ненайденных объектах;
- сканирование инвентаря ограничено 80 предметами на пакет;
- предметные данные синхронизируются только после заметного изменения;
- серверные сообщения появляются на старте/завершении цикла, миграции и отказах безопасности, а не каждую секунду.

## 18. Завершение проверки

1. Удалить временную зону кнопкой `[QA] Remove exterior test zone`.
2. Убедиться, что обычный клиент больше не считается находящимся в ней.
3. Перезапустить сервер ещё один раз.
4. Повторить короткую регрессию: вход, свет, вентиляция, вода, маска, ручная очистка и автоматическая очистка.

## 20. Коды отказа

| Код | Значение |
|---|---|
| `decon_access_required` | Игрок находится слишком далеко от камеры |
| `cycle_active` | Камера уже занята |
| `unknown_mode` | Неизвестный режим |
| `clean_water_required` | Недостаточно чистой воды |
| `power_required` | Автоматическому циклу не выделена мощность |
| `cleaning_agent_required` | Нет средства для ручной очистки |
| `nbc_solution_required` | Недостаточно раствора в NBC-смесителе |
| `nbc_tablet_required` | Нет NBC-таблетки для загрузки |
| `mixer_full` | Смеситель заполнен до 100% |
| `admin_required` | QA-команда отправлена не администратором |
| `no_active_cycle` | QA-завершение вызвано без текущего цикла |
| `player_dead` | Владелец умер до завершения |
