# Проверка MP-интеграции 0.4

Актуальный полный сценарий находится в
`BunkerCampaignArkMP/42.0/docs/MANUAL_TESTING.md`.

Для проверки нужен новый мир: Ark-prefab регистрируется через Basement API при
создании зон карты и не появится полностью в сохранении, созданном версией 0.2.

Включить:

1. `Bandits2`;
2. `Waterpipes`;
3. `BunkerCampaign`;
4. `BunkerCampaignArkMP`;
5. `BunkerCampaignToxicMP`;
6. `BunkerCampaignIntegration`.

Отключить оригинальные `TheArk`, `ToxicZonesSTALKERB42`, `BanditsDayOne`,
`BanditsWeekOne` и Cryogenic Winter.

Тестовые действия теперь находятся в контекстном меню правой кнопки мыши:

- повторный вход в бункер доступен любому игроку;
- создание и удаление тестовой токсичной зоны доступно администратору.

Ввод Lua-выражений в debug-консоль для smoke test больше не требуется.

## Водяной контур

Проверку можно выполнять в существующем мире: состояние версии 1 автоматически
мигрирует на версию 2 без сброса вентиляции.

1. Загрузить генераторную комнату. Если насос на `9950,12616,-4` отсутствовал в
   старом сохранении, Ark MP 0.3.5 восстановит физический объект автоматически.
2. Подождать две игровые минуты, чтобы Waterpipes выполнил цикл после ремонта
   серверной регистрации.
3. Открыть контекстное окно `Bunker: systems status`.
4. Проверить раздел `WATER`: `Adapter = Online`, источник
   `underground_well`, состояние и заряд совпадают с окном самого насоса.
5. При работающем насосе расходомер должен давать ненулевой поток в `L/min`;
   при выключении насоса средствами Waterpipes поток станет нулевым.
6. Перезапустить сервер и повторить проверку. Не должно появляться дубликатов
   насоса или труб, а значения исправности и фильтра должны продолжиться.

Если у насоса нет электричества, ожидаемы `Pump = Disabled`, `Status = offline`
и нулевой поток. Если фильтр подземного источника исчерпан, ожидаемы
`Status = contaminated` и `Water contamination = 100%`.
