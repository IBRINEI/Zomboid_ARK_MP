# Матрица переиспользования модов

## The Ark → BunkerCampaignArkMP

Переиспользуются локальные копии:

- `ark_underground_all.pzby` и `ark_twinrooms.pzby`;
- tilepack, модели, предметы и оформление помещений;
- функции `Build` и `Prepare` для 22 помещений;
- структура данных вентиляции, генераторов, воды и воздухозаборников.

Не загружаются:

- патчи меню, создания персонажа и SpawnRegions;
- `BWOASequence`, сюжет и миссии;
- `BWOANPC` и постоянные NPC;
- локальные контроллеры NOAH, климата и дверей.

Два bunker-prefab регистрируются отдельным общим обработчиком через Basement
API. Сервер строит и подготавливает помещения только после загрузки всех
контрольных точек карты. `BunkerCampaign` остаётся источником истины для
вентиляции; оригинальный NOAH пока не используется.

## Toxic Zones STALKER B42 → BunkerCampaignToxicMP

Переиспользуются ресурсы, одежда, маски, фильтры, дозиметр, loot/foraging и
рецепты. Оригинальный клиентский обработчик урона и клиентская админ-панель не
загружаются.

Сервер владеет:

- прямоугольными токсичными зонами;
- экспозицией персонажа;
- расходом фильтра;
- смертельным исходом;
- административным добавлением и удалением зон.

Клиент получает только данные для оверлея и звука. Рецепты передают реальный
остаток `modData.percent` между фильтром и маской.

## Bandits и Waterpipes

Bandits остаётся зависимостью контентной основы, но постоянные NPC The Ark не
создаются. Waterpipes остаётся владельцем виртуальных насосов, труб, приёмников,
фильтра и минутного перемещения воды. Интеграция не копирует его симуляцию:

- на сервере проверяет наличие физического бункерного насоса;
- восстанавливает только фиксированные записи насоса, труб, расходомера и
  подключения здания, если Ark не смог зарегистрировать их клиентскими командами;
- задаёт насосу подземный источник `TaintedWater`;
- агрегирует только ёмкости внутри координат бункера;
- передаёт в `BunkerCampaign` нормализованный снимок воды.

Объекты Waterpipes за пределами бункера не изменяются.

## Cryogenic Winter

В основной профиль не включается. Климатическая интеграция ещё не возвращена и
будет проектироваться отдельно, чтобы исключить конкурирующие изменения погоды.
